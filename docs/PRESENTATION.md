# 讲解思路

本文是做 PPT、视频和答辩讲稿时用的底稿：按“提出问题 → 看图 → 得出结论 → 引出下一个问题”的顺序，一层层讲清项目的思路。设计细节见 [DEVELOPMENT.md](DEVELOPMENT.md)，决策过程见 [devlog.md](devlog.md)，公式推导见 [DERIVATIONS.md](DERIVATIONS.md)。

每一节按同一个格式写：

- **要回答的问题**：这一节想弄清什么。
- **图**：用哪张图，怎么生成。
- **图上能读出什么**：逐条列出，先教怎么读坐标，再讲整体，最后讲局部。
- **结论**：一两句话。
- **引出的下一个问题**：为什么要接着看下一节。
